把桌面变成可测量的信号，
而不是一堆截图

大多数桌面代理的做法是「截一张图丢给模型」。dsh-deputy 换了个方向：先量化变化， 只有分数越过阈值才付一张图的成本；真要看时压成 4×4 联系表； 真要动手时，在真正隔离的 Windows 桌面里点，而不是在你的桌面上点。

观察 → 动作 → 校验，
三步一个闭环

每一次动作都被当作一次实验：做之前在动作区域留基线，做完立刻复采，把结果分成「生效」「没效果」「有副作用」三种。 没生效就重试或换策略，有副作用就停下并报告——而不是假设自己点对了。

01 / observe

采一帧，只算分数

dHash 汉明距离与 8×8 网格逐格差值加权成 0..1 的分数，落在四档之一。低档直接返回文字，不烧掉一次视觉预算。

→ score · tier · box
02 / act

在隔离桌面里动手

UIA 找控件、SendInput 发事件、或直接起进程。所有动作都发生在独立桌面，你的主桌面不会被抢焦点。

→ uia / input / shell / wait
03 / verify

复采，判三分

只在动作区域内比对，避免整屏噪声干扰。得分不足则判「没效果」并重试，区域外出现大变化则判「有副作用」。

→ ok / no-effect / side-effect
deputy_sense

采样一帧并返回分数与档位。它就是预算阀门：still 与 minor 只需要一次像素比对，不需要模型去看图。

deputy_act

执行一个动作并自动校验。参数是 kind + payload + 期望变化量，返回值是三分结论与重试次数。

deputy_sheet

把缓冲里「值得看」的帧压成一张 4×4 联系表推进会话，一次只花一张图的额度，帧序号直接烧进图像里。

deputy_desktop

开会话、拉程序、取窗口树、关桌面。状态机只有 idle → opened → running → closed 四态，关掉是幂等的。

嵌在 DSH 界面里
那块能点的虚拟桌面

左侧导航（插件 / 自动化任务 / 上下文洞察 / 学习 / 更多）不是公开插槽，三方插件塞不进去。 插件能用的席位是壳层浮层、右侧详情位、左栏底部动作位、右侧文档 tab —— dsh-deputy 选了壳层浮层， 官方文档里常态置顶窗口本来就该待在这里。

正在使用

 整帧浮层

可容纳一块持续刷新的画面，位置与尺寸由用户拖动决定；不抢占正文区域，收起后不留痕迹。
details右侧单例槽

一次只能挂一个内容，宽度固定，适合表单与检查清单，不适合随时要看的桌面画面。
sidebar.footer.action左栏底部动作位

只是一个按钮位，点开还得另找地方渲染；留作后续「一键唤起」的入口。
sidebar.right.tab.document右侧文档 tab

会被文档流管理，滚动与缩放都不受插件控制，画面比例容易失真。

面板怎么取画面127.0.0.1:17872

插件在宿主里起一个只绑回环地址的 HTTP 数据面，浮窗每 700 ms 拉一次当前帧，点画面就把归一化坐标回传。

# 只绑回环，不出网
GET  /api/health      → 宿主平台与版本
GET  /api/frame       → base64 灰度 PNG
POST /api/open        → 开隔离桌面
POST /api/input       → {op:'click',x,y}
POST /api/close       → 收起并回收

点下去的坐标归一化 0..1

浮窗把点击位置换算成 0..1 的比例再回传，宿主侧按当前桌面分辨率还原成像素。窗口被拖大拖小，点哪儿还是点哪儿。

// client.js
onPointerDown(e) {
  const r = e.currentTarget.getBoundingClientRect()
  const x = (e.clientX - r.left) / r.width
  const y = (e.clientY - r.top)  / r.height
  await post('/api/input', { op:'click', x, y })
}

装上之后
你会看到什么

安装走 DSH 的插件页，或者直接给 pnpm 一条指令。装完左下角会多一个「桌面」胶囊：点开是浮窗， 没开桌面、已关闭、宿主不是 Windows 三种空态各有各的说明，不会只给你一个转圈。

在 DSH 里装插件页 · 添加

输入包名 dsh-deputy，来源选中国大陆镜像源或 npm 官方源都可以。换版本前先卸载旧版。

# 官方源
pnpm add dsh-deputy --registry=https://registry.npmjs.org/

# 国内镜像
pnpm add dsh-deputy --registry=https://registry.npmmirror.com/

自己验一遍可选

仓库里带 21 项测试与插件清单校验，全在本地跑，不需要真的开桌面。

git clone https://github.com/bgsgp/dsh-deputy
cd dsh-deputy
node test/run-tests.mjs      # 21 项
node scripts/check-plugin.mjs # 清单校验
node scripts/publish-npm.mjs  # dry-run 看会发什么

已知边界

  • 真画面只有 Windows 有。非 win32 宿主上工具仍会注册，面板会明确写「宿主不是 Windows」，而不是假装能采帧。
  • 开隔离桌面要管理员。CreateDesktopW 与 SetThreadDesktop 权限不足时插件直接报错，不会悄悄降级到你的主桌面。
  • 输入目前只有 click 与 type。拖拽、滚轮、组合键还没进协议。
  • 面板是 700 ms 采样，不是视频流。快速动画会看起来一顿一顿，这是刻意的——它要的是「变没变」，不是「多流畅」。
  • 客户端契约还在 rc 阶段。DSH 的插槽 API 还会变，浮窗加载失败时先看宿主版本，再看 CSP 是否允许访问 127.0.0.1。
